# Мой бюджет

Учебный проект №11: настольное приложение для учёта доходов и расходов на Python и Tkinter.

## Возможности

- Добавление, редактирование и удаление операций
- Для каждой записи: дата, сумма, категория, комментарий, тип (доход или расход)
- Расчёт дохода, расхода и остатка за выбранный период
- Фильтрация списка по месяцу и по типу операции
- Сохранение данных между запусками (файл `budget.json`)
- Проверка ввода: сумма должна быть числом больше нуля, дата в формате ДД.ММ.ГГГГ

## Требования

- Python 3.9 или новее
- Внешние библиотеки не нужны, используется только стандартная библиотека
- Tkinter (входит в Python на Windows и macOS; на Linux: `sudo apt install python3-tk`)

## Запуск

```
python3 main.py
```

На Windows обычно `python main.py`. Файл `budget.json` создаётся рядом с программой при добавлении первой записи.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа |
| `models.py` | Класс `Operation` (одна запись) и константы |
| `storage.py` | Чтение и запись данных в JSON |
| `service.py` | Логика: добавление, изменение, удаление, фильтры, итоги, проверка ввода |
| `ui.py` | Окно приложения на Tkinter |

Интерфейс работает только через `BudgetService` и не обращается к файлу данных напрямую, так логика отделена от оформления.

## Контрольный сценарий

1. Добавить доход 10 000 ₸ и расход 2 500 ₸.
2. Остаток должен увеличиться на 7 500 ₸.
3. Закрыть программу и запустить снова: данные должны сохраниться.

## Технические решения

- Суммы хранятся и считаются через `Decimal`, чтобы не было ошибок округления, как у `float`.
- Данные лежат в JSON: формат простой и читаемый.
- Каждая операция имеет уникальный `id`, поэтому редактирование и удаление не зависят от порядка в таблице.
